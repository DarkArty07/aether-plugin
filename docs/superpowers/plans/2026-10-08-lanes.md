# Lanes: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Aether mode.** All eleven tasks suit the swarm: `aether-plan compile <plan>`. This is a contract plan (A10): each task gives the interfaces, the failing tests in full and the acceptance, and the implementer writes the code. The swarm that builds this plan runs the plugin from `main` (0.3.0), so the plan's Tier lines may name an effort and its tasks may have a Review line. After the swarm, the Lead runs the real checks in "After the swarm".

**Goal:** Run Aether's calls (implementer attempts, supervisor reviews, the final review and the Designer's rounds) on the owner's agy plan while its quota lasts, with the native Claude agents as the fallback, and report the quota consumed and the dollars at list price.

**Architecture:**
- **`config/lanes.json` and `lib/lanes.js`** hold the table of lane models and the pure rules: routing, digests, quota math, the lane log, and the one way to kill a lane process.
- **`lib/harness/agy.js`** is the only file that knows agy's command line and JSON.
- **`lib/lane-work.js`** prepares the workspaces (the unit worktree, or a disposable copy for read-only roles) and checks git after each call. `aether-wt sweep` cleans up after lanes.
- **`bin/aether-lane`** with **`lib/lane-calls.js`** starts a detached runner per call. The runner drives agy, checks, records and writes the result; `wait`, `result` and `stop` serve the workflow.
- **The workflow** reaches `aether-lane` through `ops` (the only LLM step, one fixed command). The usage meter mod saves each lane prompt to a file byte for byte, and a digest guards both directions.
- **`lib/lane-design.js`** runs the Designer's rounds on agy as transactions, for the Lead.
- **`aether-report`** adds the lanes: the quota consumed per group and window, and the dollars at list price.

**Tech Stack:** Node.js 22, CommonJS, `node:test`, no dependencies. Claude Code 2.1.295 plugin agents, skills, the usage meter mod (`claude-code/testing`) and dynamic workflows. agy 1.3.2 (`~/.local/bin/agy`); tests use a fake agy, never the real one.

**Spec:** `docs/superpowers/specs/2026-10-08-lanes-design.md`

## Review Focus

1. **A pid file that points at a recycled pid,** an unrelated process that now holds the number. `killGroup` must leave it alone, because it lacks the marker. Task 1 tests it.
2. **A lane prompt whose text holds a line that looks like the payload marker,** such as a plan that quotes it. The mod writes everything after the first marker line, byte for byte, so the digest still matches. Task 2 tests it.
3. **agy output in an unexpected shape:** `structured_output` as a string, a missing required key, extra keys. It must be non-clean (`no structured output`), never trusted. Task 5 tests it.
4. **A relaunch that reuses a call id whose `result.json` is still on disk.** `start` must clear it, so `wait` never returns the old result. Task 10 tests it.
5. **Another unit merging while a lane call runs.** The integration branch moves forward, which must stay `ok`; only a rewind blocks. Task 7 tests it.

### Task 1: The lane table and the lane library

**Aether:**
- Tier: haiku — about a dozen small pure functions, each pinned by exact tests and test vectors
- Review: xhigh — killGroup sends signals to process groups; a wrong check kills an unrelated process
- Area: lanes-core
- Owns: `plugins/aether/config/lanes.json`, `plugins/aether/lib/lanes.js`, `tests/lanes.test.js`
- Depends on: none

**Files:**
- Create: `plugins/aether/config/lanes.json`
- Create: `plugins/aether/lib/lanes.js`
- Test: `tests/lanes.test.js`

**Interfaces:**
- Consumes: nothing new.
- Produces, in `plugins/aether/lib/lanes.js`:
  - `CONFIG_FILE`: `path.join(__dirname, '..', 'config', 'lanes.json')`.
  - `ROLES`: `['implementer', 'supervisor', 'reviewer', 'designer']`.
  - `configPath(): string`: `process.env.AETHER_LANES_CONFIG` when set, else `CONFIG_FILE`.
  - `loadConfig(file = configPath()): object | null`. It returns null when the file does not exist. It throws an `Error` whose message starts with `lanes config <file>: ` when the file is not JSON, or when any rule below fails. The message then reads:
    - `reserve must be a number from 0 to 1`;
    - `harness <name>: <field> <problem>`, for `command`, `maxParallel`, `waitSeconds`, `timeouts` and `groups`;
    - `harness <name>, model <id>: <field> <problem>`, for `group`, `replaces`, `roles` and `levels`.

    The rules:
    - `reserve` is a number from 0 to 1;
    - `harnesses` is an object. Each harness has:
      - a non-empty string `command`;
      - integers `maxParallel` ≥ 1 and `waitSeconds` ≥ 1;
      - `timeouts` with integer `implementer`, `supervisor`, `reviewer` and `designer` ≥ 1;
      - a `groups` object of strings;
      - a `models` object. Each model has a `group` that is a key of `groups`, `replaces` in `haiku`/`sonnet`/`opus`, a non-empty `roles` array within `ROLES`, and `levels` mapping each of `low`, `medium`, `high` and `xhigh` to `low`, `medium` or `high`.
  - `commandInstalled(command, env = process.env): boolean`. True for an absolute path to an executable file. A bare name is looked up in each directory of `env.PATH`, and is found when it is executable there.
  - `laneFor(config, role, model, effort): { harness, model, group, agyModel } | null`. It searches the harnesses and their models in object order, and takes the first model whose `replaces` is `model` and whose `roles` include `role`. `agyModel` is `<model id>-<levels[effort]>`. It returns null when `config` is null, `role` is not in `ROLES`, `effort` is `max` or has no level, or no model fits.
  - `lanesArgs(config, { installed }): object | null`. It takes the first harness, in object order, for which `installed(name, harness)` is true, and returns:

        { harness, maxParallel, waits: { implementer, supervisor, reviewer }, calls }

    - `waits[role]` is `Math.ceil(timeouts[role] / waitSeconds) + 1`.
    - `calls` has a key for each of `implementer`, `supervisor` and `reviewer` that some model serves. It maps each native model to `{ model: <model id>, group }`. The designer is not in it.
    - It returns null when `config` is null or no harness is installed.
  - `digest(text): string`. FNV-1a 32-bit over the UTF-16 code units: start at `0x811c9dc5`; for each code unit, XOR it in, then `Math.imul` by `0x01000193` and `>>> 0`. The result is eight lowercase hex digits, a colon and `text.length`.
  - `canonicalJson(value): string`. JSON with the object keys sorted at every level, array order kept, `undefined` members left out, and no whitespace.
  - `resultDigest({ result, lane }): string`: `digest(canonicalJson({ result, lane }))`.
  - `usable(groupQuota, reserve): boolean`. `groupQuota` is `{ windows: { <window>: { remaining, resetsAt } } }`. It is true when there is at least one window and every `remaining` is greater than `reserve`. A null `groupQuota` is false.
  - `quotaConsumed(readings): { <window>: { consumed, resets } }`. `readings` is `[{ time, windows }]`, in any order; sort it by `time`. For each window, look at each consecutive pair of readings that both have it:
    - the same `resetsAt` adds `max(0, earlier.remaining - later.remaining)` to `consumed`;
    - a different one adds 1 to `resets`.
  - `laneTokens(usage): { input, output, cacheRead, cacheWrite }`. From agy's `{ input, output, thinking, cacheRead, total }`, with missing numbers as 0:
    - `output` is `output + thinking` when `thinking > 0` and `total >= input + output + thinking`, and `output` alone otherwise;
    - `cacheWrite` is 0.
  - `logFile(dataDir, session): string`: `<dataDir>/lanes/<session>.jsonl`. A session that does not match `/^[A-Za-z0-9_-]+$/`, null included, becomes `unknown`.
  - `appendLog(dataDir, session, entry): void` creates the directory and appends `JSON.stringify(entry)` and a newline.
  - `readLog(dataDir, { since = 0 } = {}): object[]` reads every `*.jsonl` under `<dataDir>/lanes`:
    - it skips lines that are not JSON, and entries whose `time` is below `since`;
    - an entry with no `session` gets the file's name, or null for `unknown.jsonl`;
    - it returns the entries sorted by `time`, keeping the order of entries with equal times.
  - `pruneLog(dataDir, { days = 30, now = Date.now() } = {}): { pruned: string[] }`. It deletes the `.jsonl` files not modified for `days`, and returns their sessions (the file names without `.jsonl`), sorted. A missing directory gives `{ pruned: [] }`.
  - `killGroup(pidFile, marker): { killed: boolean, pid: number | null }`:
    - A missing pid file gives `{ killed: false, pid: null }`.
    - Otherwise it reads the decimal pid, then deletes the pid file in every case.
    - The process is ours when one NUL-separated entry of `/proc/<pid>/environ` is exactly `AETHER_LANE_CALL=<marker>`, and its `/proc/<pid>/stat` state is not `Z`. If it is not ours, it returns `{ killed: false, pid }` and sends nothing.
    - If it is ours, it sends `SIGTERM` to the group `-pid`, ignoring `ESRCH`. It polls every 50 ms, for up to 2 s, until the process is gone or a zombie, waiting synchronously with `Atomics.wait`. It then sends `SIGKILL` to `-pid` if the process is still there, and returns `{ killed: true, pid }`.
  - `module.exports` holds all of the above.

'use strict'

const test = require('node:test')
const assert = require('node:assert/strict')
const fs = require('node:fs')
const path = require('node:path')
const { spawn } = require('node:child_process')
const { tempDir } = require('./helpers.js')
const lanes = require('../plugins/aether/lib/lanes.js')

const close = (a, b) => Math.abs(a - b) < 1e-9
const shipped = () => lanes.loadConfig(lanes.CONFIG_FILE)
const LEVELS = { low: 'low', medium: 'medium', high: 'high', xhigh: 'high' }

function writeConfig(t, mutate) {
  const config = JSON.parse(fs.readFileSync(lanes.CONFIG_FILE, 'utf8'))
  mutate(config)
  const file = path.join(tempDir(t), 'lanes.json')
  fs.writeFileSync(file, JSON.stringify(config))
  return file
}

function withEnv(t, name, value) {
  const previous = process.env[name]
  if (value === undefined) delete process.env[name]
  else process.env[name] = value
  t.after(() => {
    if (previous === undefined) delete process.env[name]
    else process.env[name] = previous
  })
}

// A long-running process in its own group, with the lane marker in its environment or without one.
function sleeper(t, marker) {
  const env = { ...process.env }
  delete env.AETHER_LANE_CALL
  if (marker) env.AETHER_LANE_CALL = marker
  const child = spawn(process.execPath, ['-e', 'setInterval(() => {}, 1000)'], { detached: true, stdio: 'ignore', env })
  const exited = new Promise((resolve) => child.on('exit', resolve))
  t.after(() => {
    try {
      process.kill(-child.pid, 'SIGKILL')
    } catch {
      // already gone
    }
  })
  return { pid: child.pid, exited }
}

test('digest is FNV-1a over UTF-16 code units with the length, and resultDigest ignores key order', () => {
  assert.equal(lanes.digest(''), '811c9dc5:0')
  assert.equal(lanes.digest('a'), 'e40c292c:1')
  assert.equal(lanes.digest('foobar'), 'bf9cf968:6')
  assert.equal(lanes.digest('é'), '6c0b6c44:1')
  assert.equal(lanes.digest('😀'), 'cb31c4b8:2')

### Task 5: The agy adapter

**Aether:**
- Tier: haiku — one module whose parsing rules exact tests and recorded output shapes pin down
- Review: xhigh — input parsing: agy reports success on runs that failed, and a lax check trusts them
- Area: harness
- Owns: `plugins/aether/lib/harness/agy.js`, `tests/harness-agy.test.js`
- Depends on: Task 1 — installed() uses commandInstalled from lib/lanes.js

**Files:**
- Create: `plugins/aether/lib/harness/agy.js`
- Test: `tests/harness-agy.test.js`

**Interfaces:**
- Consumes: `commandInstalled(command, env)` from `plugins/aether/lib/lanes.js` (Task 1).
- Produces: `createAgy({ command = 'agy', groups = {}, exec = defaultExec, env = process.env } = {})`. `groups` maps a group key to agy's group name, such as `{ gemini: 'Gemini Models' }`. It returns:
  - `name`: `'agy'`.
  - `installed(): boolean`: `commandInstalled(command, env)`.
  - `quota(): { groups: { <key>: { windows: { <window>: { remaining, resetsAt } } } } }`:
    - It runs `exec([command, '-p', '/usage', '--output-format', 'json'], { timeoutMs: 60000 })`.
    - It reads `command.data.groups[]`. A group whose `name` is a value of `groups` is reported under its key, with each bucket as `windows[bucket.window] = { remaining: bucket.remaining_fraction, resetsAt: bucket.reset_time }`. Other groups are left out.
    - A non-zero status throws `Error('agy /usage failed: exit <status>: <stderr, trimmed, first 300 characters>')`, and output that is not JSON throws `Error('agy /usage failed: unreadable output')`.
  - `argv({ model, schemaFile, timeoutSeconds, prompt, conversation = null }): string[]` returns `[command, '-p', prompt, '--model', model, '--output-format', 'json', '--json-schema', schemaFile, '--dangerously-skip-permissions', '--print-timeout', `${timeoutSeconds}s`]`, followed by `'--conversation', conversation` when it is given.
  - `parse({ stdout, stderr, exitCode }, { conversation = null, required = [] } = {})` returns `{ clean, reason, structured, usage, conversation, response }`.
    - `usage` is `{ input, output, thinking, cacheRead, total }`, from `input_tokens`, `output_tokens`, `thinking_tokens`, `cache_read_tokens` and `total_tokens`, with 0 for missing values.
    - `conversation` is `conversation_id`, or null.
    - `structured` is `structured_output` when it is a plain object, else null.
    - `reason` is the first rule that fails, in this order, and null when the result is clean:
      1. `exitCode !== 0` gives `exit <code>`, plus `: <error>` when the output parses and has an `error`;
      2. stdout that is not JSON gives `unreadable output`;
      3. `status !== 'SUCCESS'` gives `status <status>`, plus `: <error>` when there is one;
      4. stderr that is not empty after trimming gives `stderr: <its first line, trimmed, first 300 characters>`;
      5. an empty `response` after trimming gives `empty response`;
      6. `structured_output` that is not a plain object, or lacks one of the `required` keys, gives `no structured output`;
      7. a `conversation` given, with a `conversation_id` that differs, gives `conversation <got> instead of <asked>`.
    - `clean` is `reason === null`.
  - `usageDelta(previous, current)` returns each field of `current` minus `previous`, but never below 0. A null `previous` returns `current`.
  - `version(): string | null` runs `exec([command, '--version'], { timeoutMs: 10000 })`, and returns the first `\d+\.\d+\.\d+` of stdout on status 0. It returns null on any other status, on no match, or when `exec` throws.
  - `defaultExec(argv, { timeoutMs, cwd })` runs `spawnSync(argv[0], argv.slice(1), { encoding: 'utf8', timeout: timeoutMs, cwd, maxBuffer: 64 * 1024 * 1024 })` and returns `{ status, stdout, stderr }`.
  - `module.exports = { createAgy }`.

// The runtime replays a resumed run by repeating its calls, so a workflow may not read the
// clock or random numbers. These stand-ins make any such read fail the test.
function forbidden(what) {
  return () => {
    throw new Error(`${what} is not allowed in a workflow`)
  }
}
function NoDate() {
  throw new Error('Date is not allowed in a workflow')
}
NoDate.now = forbidden('Date.now()')
const NoRandomMath = Object.create(Math, { random: { value: forbidden('Math.random()') } })

function loadWorkflow() {
  const source = fs.readFileSync(SCRIPT, 'utf8')
  if (!source.startsWith('export const meta = {')) throw new Error('run.workflow.js must start with `export const meta = {`')
  const body = source.replace('export const meta', 'const meta')
  if (/^\s*(import|export)\b|\bimport\s*\(/m.test(body)) throw new Error('a workflow cannot import modules')
  return new AsyncFunction('agent', 'parallel', 'pipeline', 'phase', 'log', 'args', 'Date', 'Math', 'require', 'process', body)
}

// What a clean aether-wt prints for each command the workflow gives the ops agent.
function aetherWt(call, state) {
  const [first, second] = call.command.rest
  switch (call.command.verb) {
    case 'merge':
      state.merged.add(second)
      return { merged: true, commit: `merge-${second}` }
    case 'remove':
      return { removed: true, patch: state.merged.has(second) ? null : path.join(state.args.runDir, 'patches', `${second}.patch`) }
    case 'diff':
      return { path: path.join(state.args.runDir, 'packages', 'final.diff'), base: state.args.integration.base, head: 'f1a1' }
    case 'sweep':
      return { removedWorktrees: [], removedBranches: [], remaining: { worktrees: [], branches: [] } }
    default:
      throw new Error(`unexpected command for run ${first}: ${call.command.line}`)
  }
}

const LEVEL = { low: 'low', medium: 'medium', high: 'high', xhigh: 'high' }
const GROUP = { 'gemini-3.8-flash': 'gemini', 'claude-sonnet-5-5': 'claude', 'claude-opus-5-5': 'claude' }

// The lane block of a finished call, built from the flags its start was given.
function laneOf(started) {
  return {
    harness: 'agy',
    model: `${started.model}-${LEVEL[started.effort]}`,
    group: GROUP[started.model],
    effort: started.effort,
    durationMs: 1000,
    usage: { input: 1000, output: 200, thinking: 0, cacheRead: 500, total: 1200 },
    conversation: `conv-${started.call}`,
  }
}

// What aether-lane prints for a finished call, with the digest it computes.
function laneAnswer({ status = 'ok', result = null, lane, detail = '', files = null }) {
  const answer = { done: true, status, result, lane, detail }
  if (files) answer.files = files
  answer.digest = lanes.resultDigest({ result, lane })
  return answer
}

// What a clean aether-lane prints: every group usable, every call started, and every wait done
// with the role's default answer.
function aetherLane(call, defaults) {
  switch (call.command.verb) {
    case 'status':
      return { harnesses: { agy: { installed: true, version: '1.3.2', groups: { gemini: { usable: true }, claude: { usable: true } } } } }
    case 'start':
      return { started: true, model: `${call.lane.model}-${LEVEL[call.lane.effort]}`, group: GROUP[call.lane.model] }
    case 'wait':
    case 'result': {
      if (!call.started) return { error: `no such lane call: ${call.lane.call}` }
      const role = call.started.role
      const result = defaults[role]({ role, unit: call.started.task || null, n: 1, lane: call.started })
      return laneAnswer({ result, lane: laneOf(call.started) })
    }
    case 'stop':
      return { stopped: [call.lane.call] }
    default:
      throw new Error(`unexpected aether-lane command: ${call.command.line}`)
  }
}

// Default answers: every implementer finishes, every supervisor approves, the final reviewer
// passes, and every ops command succeeds.
function defaultHandlers(state) {
  const defaults = {
    implementer: () => ({ status: 'DONE', summary: 'Implemented the brief.', head: 'abc1234', tests: '3/3 pass', concerns: '', question: '' }),
    supervisor: () => ({ verdict: 'approve', findings: [], ruling: 'Approve: the diff meets the brief.', guidance: '', question: '' }),
    reviewer: () => ({ verdict: 'ready', findings: [], declined: [], summary: 'Ready to merge.' }),
    ops: (call) => aetherWt(call, state),
  }
  defaults.lane = (call) => aetherLane(call, defaults)
  return defaults
}

function parseCommand(prompt) {
  const m = prompt.match(/(aether-wt|aether-lane) ([a-z]+)((?: [^\s']+)*)/)
  if (!m) return null
  return { tool: m[1], line: m[0], verb: m[2], rest: m[3].trim().split(' ').filter(Boolean) }
}

// The run, the call and the --flags of an aether-lane command.
function laneFlags(rest) {
  const flags = { run: rest[0], call: rest[1] }
  for (let i = 2; i < rest.length; i += 2) flags[rest[i].replace(/^--/, '')] = rest[i + 1]
  return flags
}

function payloadOf(prompt) {
  const m = /^=== aether-lane payload: (.+) ===$/m.exec(prompt)
  return m ? { path: m[1], text: prompt.slice(m.index + m[0].length + 1) } : null
}

// The args as the stubs see them. Invalid input is the workflow's to reject, not the harness's.
function parseLeniently(args) {
  let value = args
  for (let i = 0; i < 2 && typeof value === 'string'; i++) {
    try {
      value = JSON.parse(value)
    } catch {
      return null
    }
  }
  return value
}

// Lets the other units' calls start before this one goes on.
function tick() {
  return new Promise((resolve) => setImmediate(resolve))
}

// Runs the workflow with `args`. A handler in `overrides` replaces the default for its role and
// gets (call, fallback): `call` describes the agent call, with `n` counting this role's calls for
// the unit (ops: for the unit and command); `fallback` is the default handler. An ops handler
// returns what aether-wt would print, or null for an agent that failed. `overrides.lane` answers
// aether-lane commands the same way, and may also return a string, printed as it is.
//
// An aether-lane call also carries `lane` (its run, call and flags), `payload` ({ path, text }, for
// a start), `digestOk` (for a start: whether --digest matches the payload) and `started` (for a
// wait, result or stop: the flags its start was given).
//
// Resolves to { result, error, calls, events, logs, maxActive }. `events` holds "start <key>" and
// "end <key>" lines in order, where <key> is the role (and ops command) plus the unit.
async function runWorkflow(args, overrides = {}) {
  const state = { args: parseLeniently(args), merged: new Set(), lanes: {} }
  const defaults = defaultHandlers(state)
  const calls = []
  const events = []
  const logs = []
  const active = {}
  const maxActive = {}

  async function agent(prompt, opts = {}) {
    if (!opts.agentType) throw new Error('every agent call needs an agentType')
    const role = opts.agentType.replace(/^aether:/, '')
    if (!['implementer', 'supervisor', 'reviewer', 'ops'].includes(role)) throw new Error(`unknown agent type: ${opts.agentType}`)
    const unitMatch = (opts.label || '').match(/^(task-\d+):/)
    const command = role === 'ops' ? parseCommand(prompt) : null
    const isLane = Boolean(command && command.tool === 'aether-lane')
    const call = {
      role,
      model: opts.model,
      effort: opts.effort,
      label: opts.label,
      phase: opts.phase,
      schema: opts.schema,
      prompt,
      unit: unitMatch ? unitMatch[1] : null,
      command,
      lane: isLane ? laneFlags(command.rest) : null,
      payload: isLane ? payloadOf(prompt) : null,
    }
    if (isLane && command.verb === 'start') {
      call.digestOk = Boolean(call.payload) && lanes.digest(call.payload.text) === call.lane.digest
      state.lanes[call.lane.call] = call.lane
    }
    if (isLane && command.verb !== 'start') call.started = state.lanes[call.lane.call] || null
    const kind = command ? (isLane ? `ops:lane-${command.verb}` : `ops:${command.verb}`) : role
    call.n = calls.filter((c) => c.unit === call.unit && c.kind === kind).length + 1
    call.kind = kind
    calls.push(call)
    const key = call.unit ? `${kind} ${call.unit}` : kind
    active[kind] = (active[kind] || 0) + 1
    maxActive[kind] = Math.max(maxActive[kind] || 0, active[kind])
    events.push(`start ${key}`)
    try {
      await tick()
      const handler = isLane ? overrides.lane || defaults.lane : overrides[role] || defaults[role]
      const answer = await handler(call, isLane ? defaults.lane : defaults[role])
      if (role !== 'ops' || answer === null) return answer
      if (typeof answer === 'string') return { exitCode: 0, stdout: answer }
      return { exitCode: answer.error ? 1 : 0, stdout: `${JSON.stringify(answer)}\n` }
    } finally {
      await tick()
      active[kind]--
      events.push(`end ${key}`)
    }
  }

  const parallel = (thunks) => Promise.all(thunks.map((thunk) => thunk()))
  const pipeline = forbidden('pipeline() in this harness')
  const phase = (title) => events.push(`phase ${title}`)
  const log = (message) => logs.push(String(message))

  let result = null
  let error = null
  try {
    result = await loadWorkflow()(agent, parallel, pipeline, phase, log, args, NoDate, NoRandomMath, undefined, undefined)
  } catch (err) {
    error = err
  }
  return { result, error, calls, events, logs, maxActive }
}

module.exports = { runWorkflow, laneAnswer, laneOf }

function lane(args, verb, rest, env) {
  return runBin(LANE_BIN, [verb, args.runId, ...rest], args.repoRoot, env)
}

// Waits for a lane call to finish, up to `seconds`.
function waitDone(args, call, env, seconds = 60) {
  const deadline = Date.now() + seconds * 1000
  while (Date.now() < deadline) {
    const r = lane(args, 'wait', [call, '--max', '5'], env)
    if (r.json && r.json.error) throw new Error(r.json.error)
    if (r.json && r.json.done) return r.json
  }
  throw new Error(`lane call ${call} did not finish in ${seconds} s`)
}

function agyCalls(env) {
  if (!fs.existsSync(env.FAKE_AGY_LOG)) return []
  return fs
    .readFileSync(env.FAKE_AGY_LOG, 'utf8')
    .split('\n')
    .filter(Boolean)
    .map((line) => JSON.parse(line))
}

// The calls that ran a turn, not /usage or --version.
function agyTurns(env) {
  return agyCalls(env).filter((c) => c.argv[0] === '-p' && c.argv[1] !== '/usage')
}

function argAfter(argv, name) {
  const i = argv.indexOf(name)
  return i === -1 ? null : argv[i + 1]
}

function roleBody(role) {
  const text = fs.readFileSync(path.join(PLUGIN, 'agents', `${role}.md`), 'utf8')
  return text.slice(text.indexOf('\n---\n', 4) + 5).trim()
}

function git(cwd, ...args) {
  const r = spawnSync('git', args, { cwd, encoding: 'utf8' })
  if (r.status !== 0) throw new Error(`git ${args.join(' ')}: ${r.stderr}`)
  return r.stdout.trim()
}

function alive(pid) {
  try {
    const stat = fs.readFileSync(`/proc/${pid}/stat`, 'utf8')
    return stat[stat.lastIndexOf(')') + 2] !== 'Z'
  } catch {
    return false
  }
}

    - **Superpowers.** The install is the first `superpowers@` entry's `installPath` in `<CLAUDE_CONFIG_DIR or ~/.claude>/plugins/installed_plugins.json`, and its skills are `<installPath>/skills/brainstorming/SKILL.md` and `<installPath>/skills/writing-plans/SKILL.md`.
    - **Otherwise,** it calls `run.ensureExcluded(gitCommonDir)` and creates the state with a new id (`run.newRunId()`): `{ id, session, cwd, conversation: null, agyModel, group, status: 'open', rounds: [] }`. It then runs round 1.
  - **`reply <id>`** (the owner's answer is `input`):
    - an unknown or ended id gives `{"error": "no open design <id>"}` and exit code 1;
    - a dirty `cwd` gives `{"unavailable": "dirty"}` and exit code 3;
    - otherwise it runs the next round, resuming the conversation.
  - **A round:**
    1. **The prompt.** The first round's is `[roleBody('designer'), DESIGN_NOTE, ...claudeMdSections(cwd, os.homedir()), input].join('\n\n')`; later rounds send `input` alone. It writes `DESIGNER_SCHEMA` to `<state dir>/schema.json`.
    2. **agy.** It records the starting commit (`git rev-parse HEAD`), then runs agy with `adapter.argv` (timeout: the harness's `designer`; `conversation` on later rounds) in `cwd`. agy runs detached, with `AETHER_LANE_CALL=design/<id>`, and its pid in `<state dir>/pid`, which is deleted after. It reads the quota before and after.
    3. **The outcome:**
       - **Violation.** The changed paths are the files `git diff --name-only <start>..HEAD` names, plus the uncommitted and untracked ones. One that is not under `docs/superpowers/specs/` or `docs/superpowers/plans/` is a `violation`, listing them sorted.
       - **Non-clean.** `adapter.parse` (with the conversation on later rounds, and `DESIGNER_SCHEMA.required`) gives a non-clean result: `quota` when the group is not usable afterwards, else `failed`, with the reason as `detail`.
       - **Undo.** On either, it runs `git reset -q --hard <start>` and `git clean -fdq` (never `-x`, so ignored files survive). It prints `{"failed": "<violation|quota|failed>", ["files": [...],] ["detail": "...",] "undone": true}` with exit code 4, and records the round with that status.
       - **Success.** It stores the `conversation` on round 1. The round's usage is `adapter.usageDelta` from the previous round's cumulative usage. It appends a call entry to the lane log (`run: null`, `design: <id>`, `call: 'round-<n>'`, `role: 'designer'`, `task: null`, and the other fields as in Task 8), and prints the reply with exit code 0.
  - **The reply,** exactly:

        ## For the owner
        <forOwner>

        ## For the Lead
        - Stage: <stage>
        - Waiting for: <waitingFor>
        - Files: <files>
        - Lane: agy <agyModel>, design <id>; this round <n> tokens, $<usd> at list price; <group label> used <a> % of the 5 h window and <b> % of the weekly one

    It ends with a newline after the Lane line.
    - `<n>` is `input + output + cacheRead` of `laneTokens(round usage)`.
    - `<usd>` is `priceEntry({ model: agyModel, ...laneTokens(round usage), agent: 'lane' }, loadPrices())`, with `toFixed(2)`.
    - `<a>` and `<b>` are the drop in `remaining` × 100, with `toFixed(1)`, clamped at 0. Each is `?` when either reading is missing or its `resetsAt` changed.
  - **`end <id>`** kills the design's agy, if any (`killGroup(<dir>/pid, 'design/<id>')`), removes the directory, and prints `{"ended": "<id>"}`.
  - **`list`** prints `{"designs": [{ id, session, cwd, conversation, status, rounds }]}`, sorted by id, where `rounds` is the number of rounds.
  - **`DESIGN_NOTE`,** with the two absolute skill paths and the plugin's `bin/` directory filled in, exactly:

        ## You run in an external harness

        You are the Aether Designer, run by the agy CLI rather than Claude Code. Your role above holds, with these changes:
        - You have no Skill tool. Where your role says to load a superpowers skill, read its SKILL.md and follow it: superpowers:brainstorming is <brainstorming path>, and superpowers:writing-plans is <writing-plans path>. Files those skills mention sit beside them.
        - Run aether-voice as <plugin bin>/aether-voice and aether-plan as <plugin bin>/aether-plan.
        - Commit only files under docs/superpowers/specs/ and docs/superpowers/plans/. A change to any other file undoes your whole round.
        - Your reply goes in the structured output your harness asks for: forOwner is the text of "For the owner"; stage, waitingFor and files are the bullets of "For the Lead".

**Quality bar:**
- A round starts only on a clean worktree, and an undo restores exactly the starting commit and removes only what the round created; ignored files survive.
- The reply's text is relayed to the owner verbatim, so its format must match exactly.
